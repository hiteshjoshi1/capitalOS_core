# Issue 106: Credit card UI changes

## Objective
- In the last PRD (105) we wrote a parser for Citibank Credit Card data, now it is time to show the data in the dashboard. 
- As usual the dashboard would give a consolidated picture whereas you can go deeper bu clicking inside and as usual this picture is based on the month
- Please note that there can be multiple credit cards, so the dashboard gives a consolidated view of money out.
- The detail page gives a total for that month. 
- It also shows the top purchases that month and any recurring payments, example ChatGPT, Spotify etc
- Eventually I want to map out where my purchases are going in the detail page. Example x$ is groceries, y in bills, z in travel. This however, is out of scope for this story but design should think about it
- One other eventual goal is to have correct money in (all including salary, dividends, etc) and money out (rent, bill - credit cards or otherwise) should be shown in dashboard correctly. The design should accomodate this 
- You can start by adding money out from Credit card in this story.
